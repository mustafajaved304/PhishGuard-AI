# 🛡️ PhishGuard AI

## Intelligent Phishing Detection Platform

PhishGuard AI is a Flask-based cybersecurity project developed for educational purposes. It helps users analyze URLs, emails, and SMS messages for phishing indicators using rule-based detection.

## Features

- URL Phishing Detection
- Email Phishing Detection
- SMS Scam Detection
- Risk Score Calculation
- Security Recommendations
- PDF Report Generation
- Responsive Cybersecurity Dashboard

## Technologies

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- ReportLab
